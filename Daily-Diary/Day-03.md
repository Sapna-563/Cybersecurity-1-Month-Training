# Day 03 – Introduction to Cybersecurity Tools

**Training Duration:** 1 Month  
**Day:** 03

## 1. Objective
To understand different cybersecurity tools used in Security Operations Centers (SOC) for security monitoring, threat detection, log analysis and incident response automation.

## 2. Topics Covered
- Introduction to Wazuh
- Introduction to Sysmon
- Introduction to TheHive
- Introduction to Shuffle
- Introduction to VirusTotal
- Importance of Security Monitoring Tools
- Overview of SIEM and SOAR Platforms

## 3. Learning Activities
- Studied the basic features and functions of Wazuh.
- Learned how Sysmon monitors Windows system activities and generates event logs.
- Understood how TheHive is used for security incident and case management.
- Explored the role of Shuffle in automating security workflows.
- Learned how VirusTotal helps analyse files, URLs and file hashes.
- Understood how different cybersecurity tools work together in a SOC environment.

## 4. What I Learned
I learned about different cybersecurity tools used in modern Security Operations Centers. I understood that Wazuh is used for security monitoring and log analysis, Sysmon generates detailed Windows event logs, TheHive manages security incidents, Shuffle automates workflows and VirusTotal helps check the reputation of suspicious files and URLs.

## 5. Tools Explored
- Wazuh
- Sysmon
- TheHive
- Shuffle
- VirusTotal

## 6. Challenges Faced
Understanding the different purposes of cybersecurity tools and how they work together in security monitoring and incident response.

## 7. Conclusion
The third day of training provided knowledge about important cybersecurity tools and their applications in SOC operations. It helped me understand how these tools support threat detection, log monitoring, incident management and security automation.
