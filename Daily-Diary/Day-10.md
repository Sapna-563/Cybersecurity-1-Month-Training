# Day 10 – Wazuh Installation and Initial Setup

**Training Duration:** 1 Month  
**Day:** 10

## 1. Objective
To understand the installation process and initial setup of Wazuh and learn how to prepare the Wazuh environment for security monitoring and log analysis.

## 2. Topics Covered
- Introduction to Wazuh Installation
- System Requirements for Wazuh
- Wazuh Installation Methods
- Wazuh Server Setup
- Wazuh Dashboard
- Wazuh Indexer
- Wazuh Manager
- Basic Wazuh Configuration
- Accessing the Wazuh Dashboard
- Overview of Security Monitoring Setup

## 3. Learning Activities
- Studied the basic requirements for installing Wazuh.
- Explored the Wazuh installation process and setup options.
- Learned about the main components of Wazuh.
- Understood the roles of Wazuh Manager, Wazuh Indexer and Wazuh Dashboard.
- Explored the initial configuration of the Wazuh environment.
- Learned how to access the Wazuh Dashboard through a web browser.
- Understood how the dashboard provides information about security events and monitored systems.

## 4. What I Learned
I learned that Wazuh provides a security monitoring environment through different components, including Wazuh Manager, Wazuh Indexer and Wazuh Dashboard. I understood the basic installation requirements and the purpose of each component. I also learned that the Wazuh Dashboard provides a graphical interface for viewing security alerts, monitoring systems and analysing collected data.

## 5. Tools Explored
- Wazuh
- Wazuh Manager
- Wazuh Indexer
- Wazuh Dashboard
- Ubuntu Linux
- Windows 11
- Web Browser

## 6. Challenges Faced
Understanding the installation requirements, different Wazuh components and their functions. Learning how these components work together to provide a complete security monitoring environment was also challenging.

## 7. Conclusion
The tenth day of training provided knowledge about Wazuh installation and initial setup. It helped me understand the architecture of Wazuh and the functions of its main components. This knowledge is useful for setting up a security monitoring environment and analysing security events.
