## 3. Theoretical Knowledge
During this one-month training, I gained knowledge of cybersecurity fundamentals and Security Operations Center (SOC) operations.

I learned how Windows Event Logs and Sysmon provide system activity information for security monitoring. Wazuh helps collect and analyze security events and generate alerts.

I also studied how TheHive supports security incident management, Shuffle automates repetitive security tasks, and VirusTotal provides threat intelligence for suspicious files, URLs, and IP addresses.

The integration of these tools demonstrates how a SOC environment can monitor security events, analyze potential threats, and organize incident-response activities.
