# Day 18 – Wazuh Rules and Custom Rule Configuration

**Training Duration:** 1 Month  
**Day:** 18

## 1. Objective
To understand Wazuh security rules and learn how custom detection rules are created and configured to identify suspicious activities and generate security alerts.

## 2. Topics Covered
- Introduction to Wazuh Rules
- Importance of Detection Rules
- Default Wazuh Rules
- Custom Rule Configuration
- Understanding Rule IDs
- Rule Levels and Severity
- Security Event Detection
- Introduction to Wazuh Archives
- Custom Alert Generation
- Identifying Suspicious Activities

## 3. Learning Activities
- Studied the purpose and importance of Wazuh detection rules.
- Learned how Wazuh rules analyse incoming security events.
- Explored the difference between default rules and custom rules.
- Understood how rule IDs and severity levels are used.
- Learned the basic structure of custom rule configuration.
- Explored how custom rules help detect specific suspicious activities.
- Understood how Wazuh generates alerts when events match configured rules.
- Studied the importance of archived logs for security investigation.

## 4. What I Learned
I learned that Wazuh rules are used to analyse security events and identify potentially suspicious activities. I understood that default rules detect common security events, while custom rules can be created to identify specific activities according to monitoring requirements. I also learned about rule IDs, severity levels and the importance of archived logs in security analysis.

## 5. Tools Explored
- Wazuh
- Wazuh Manager
- Wazuh Dashboard
- Wazuh Rules
- Wazuh Archives
- Windows Event Viewer
- Sysmon

## 6. Challenges Faced
Understanding the structure of Wazuh rules, identifying appropriate rule levels and learning how custom rules are configured to detect specific security events.

## 7. Conclusion
The eighteenth day of training provided knowledge about Wazuh rules and custom rule configuration. It helped me understand how detection rules analyse security events and generate alerts for suspicious activities. This knowledge is important for improving threat detection and security monitoring in a SOC environment.
