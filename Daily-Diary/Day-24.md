## 3. Theoretical Knowledge
Shuffle is an open-source security automation platform used to create workflows and automate repetitive security tasks.

SOAR stands for Security Orchestration, Automation and Response. It helps security teams connect different security tools and automate incident-response activities.

Shuffle uses workflows to connect tools and perform tasks automatically. For example, when Wazuh generates a security alert, Shuffle can receive the alert through a webhook and trigger further actions.
