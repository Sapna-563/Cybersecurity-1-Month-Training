# Day 17 – Wazuh Alerts and Security Event Investigation

**Training Duration:** 1 Month  
**Day:** 17

## 1. Objective
To understand how Wazuh generates security alerts and learn how to investigate security events by analysing alerts and identifying suspicious activities in monitored systems.

## 2. Topics Covered
- Introduction to Wazuh Security Alerts
- Understanding Alert Levels
- Wazuh Alert Generation
- Security Event Investigation
- Monitoring Suspicious Activities
- Understanding Alert Details
- Windows Security Event Analysis
- Sysmon Event Investigation
- Identifying Potential Security Threats
- Role of Alerts in SOC Operations

## 3. Learning Activities
- Studied how Wazuh generates alerts based on security events.
- Learned about different alert levels and their importance.
- Explored how security alerts are displayed on the Wazuh Dashboard.
- Understood how to examine alert details for investigating suspicious activities.
- Learned how Windows and Sysmon events help identify unusual system behaviour.
- Explored how security analysts investigate alerts to understand potential threats.
- Understood the importance of alert investigation in Security Operations Center activities.

## 4. What I Learned
I learned that Wazuh generates security alerts when monitored events match predefined detection rules. I understood that alerts contain useful information such as event details, timestamps and alert levels. I also learned how security analysts investigate alerts by examining related logs and identifying suspicious activities that may indicate a security incident.

## 5. Tools Explored
- Wazuh
- Wazuh Dashboard
- Wazuh Manager
- Windows Event Viewer
- Sysmon (System Monitor)
- Windows Security Logs

## 6. Challenges Faced
Understanding different alert levels, interpreting alert details and identifying which security events require further investigation.

## 7. Conclusion
The seventeenth day of training provided knowledge about Wazuh security alerts and event investigation. It helped me understand how alerts are generated, analysed and investigated to identify potential security threats and support incident response activities.
