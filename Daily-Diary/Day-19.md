# Day 19 – Wazuh Archives and Custom Security Alert Detection

**Training Duration:** 1 Month  
**Day:** 19

## 1. Objective
To understand Wazuh Archives and learn how archived security logs are used for detailed event analysis and how custom detection rules help identify specific suspicious activities.

## 2. Topics Covered
- Introduction to Wazuh Archives
- Importance of Archived Logs
- Wazuh Log Storage
- Understanding JSON Log Format
- Security Event Analysis
- Custom Security Alert Detection
- Introduction to Mimikatz
- Understanding Suspicious Activities
- Custom Wazuh Detection Rules
- Log Analysis and Investigation

## 3. Learning Activities
- Studied the purpose and importance of Wazuh Archives.
- Learned how archived logs help maintain records of collected security events.
- Explored the structure of security logs in JSON format.
- Understood how archived events can be used for detailed security investigations.
- Studied Mimikatz as an example of a tool associated with credential theft.
- Learned how custom Wazuh rules can be used to identify specific suspicious activities.
- Explored how security events can trigger custom alerts.
- Understood how archived logs support threat detection and incident investigation.

## 4. What I Learned
I learned that Wazuh Archives store collected security events and provide useful information for detailed log analysis. I understood how archived logs can help security analysts investigate activities that may not generate standard alerts. I also learned about Mimikatz and how custom Wazuh detection rules can help identify suspicious activities related to potential credential theft.

## 5. Tools Explored
- Wazuh
- Wazuh Archives
- Wazuh Manager
- Wazuh Dashboard
- Custom Wazuh Rules
- Sysmon
- Windows Event Viewer

## 6. Challenges Faced
Understanding the archived log structure, analysing JSON-formatted events and learning how custom detection rules identify specific suspicious activities.

## 7. Conclusion
The nineteenth day of training provided knowledge about Wazuh Archives and custom security alert detection. It helped me understand how archived logs support detailed investigations and how custom rules improve the detection of suspicious activities in a cybersecurity environment.
