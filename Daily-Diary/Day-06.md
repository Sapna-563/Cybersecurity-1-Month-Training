# Day 06 – Windows Event Logs and Security Event Analysis

**Training Duration:** 1 Month  
**Day:** 06

## 1. Objective
To understand Windows event logs in detail and learn how security-related events are recorded, monitored and analysed for identifying suspicious activities.

## 2. Topics Covered
- Introduction to Windows Event Logs
- Types of Windows Event Logs
- Understanding Event ID
- Windows Security Logs
- Successful and Failed Login Attempts
- User Account Activities
- Monitoring System Activities
- Importance of Log Analysis in Cybersecurity

## 3. Learning Activities
- Studied the structure and importance of Windows event logs.
- Explored different types of events recorded by Windows.
- Learned about Event IDs and their importance in identifying specific activities.
- Understood how successful and failed login attempts are recorded.
- Explored how security logs help identify unusual user activities.
- Learned how security analysts use event logs to investigate suspicious activities.

## 4. What I Learned
I learned that Windows event logs contain important information about system activities, user actions and security events. I understood that each event has a unique Event ID that helps identify a particular activity. I also learned that analysing successful and failed login attempts can help security analysts detect suspicious access attempts and investigate potential security incidents.

## 5. Tools Explored
- Windows Event Viewer
- Windows 11
- Security Logs
- System Logs

## 6. Challenges Faced
Understanding different Event IDs and identifying important security-related events from the large amount of information available in Windows Event Viewer.

## 7. Conclusion
The sixth day of training provided knowledge about Windows event logs and security event analysis. It helped me understand how system and user activities are recorded and how analysing these logs supports threat detection and security monitoring.
