## 3. Theoretical Knowledge
VirusTotal provides threat intelligence information about suspicious files, URLs, domains, and IP addresses. Shuffle can connect with VirusTotal through its API to automate security analysis.

An API (Application Programming Interface) allows two different applications to communicate with each other. VirusTotal API enables Shuffle to send indicators, such as file hashes, for analysis and receive the results.

In a SOC environment, when Wazuh generates a security alert, Shuffle can process the alert and send relevant information to VirusTotal. The returned threat intelligence results can help analysts understand whether an indicator is potentially malicious.
