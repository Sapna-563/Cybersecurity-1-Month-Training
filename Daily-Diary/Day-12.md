# Day 12 – Wazuh Agent Installation and Configuration

**Training Duration:** 1 Month  
**Day:** 12

## 1. Objective
To understand the installation and configuration of the Wazuh Agent on Windows systems and learn how agents collect security-related information and send it to the Wazuh Server for monitoring and analysis.

## 2. Topics Covered
- Introduction to Wazuh Agent
- Importance of Wazuh Agent
- Wazuh Agent Architecture
- Wazuh Agent Installation on Windows
- Agent Configuration
- Connecting Wazuh Agent to Wazuh Server
- Agent Registration and Authentication
- Endpoint Monitoring
- Agent Status Monitoring
- Security Log Collection

## 3. Learning Activities
- Studied the purpose and importance of the Wazuh Agent.
- Learned about the role of agents in endpoint security monitoring.
- Explored the Wazuh Agent installation process on Windows.
- Understood the basic configuration required to connect an agent with the Wazuh Server.
- Learned how agents communicate with the Wazuh Manager.
- Explored how Wazuh Agents collect security-related information from endpoints.
- Understood how agent status can be monitored through the Wazuh Dashboard.

## 4. What I Learned
I learned that the Wazuh Agent is installed on monitored devices to collect security-related information and send it to the Wazuh Manager for analysis. I understood the basic installation and configuration process and how agents communicate with the server. I also learned that Wazuh Agents help monitor endpoint activities, collect logs and detect potential security threats.

## 5. Tools Explored
- Wazuh Agent
- Wazuh Manager
- Wazuh Dashboard
- Windows 11
- Windows Event Viewer
- Ubuntu Linux

## 6. Challenges Faced
Understanding the Wazuh Agent configuration process, server connection settings and agent registration. Learning how agents communicate with the Wazuh Manager was also challenging.

## 7. Conclusion
The twelfth day of training provided knowledge about Wazuh Agent installation and configuration. It helped me understand how agents collect security information from endpoints and send it to the Wazuh Manager for monitoring, log analysis and threat detection.
