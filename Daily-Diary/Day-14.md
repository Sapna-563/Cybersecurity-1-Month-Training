# Day 14 – Windows Event Logs and Sysmon Integration with Wazuh

**Training Duration:** 1 Month  
**Day:** 14

## 1. Objective
To understand how Windows Event Logs and Sysmon logs can be integrated with Wazuh for centralized log collection, security monitoring and threat detection.

## 2. Topics Covered
- Introduction to Sysmon Log Integration
- Windows Event Logs
- Sysmon Event Logs
- Wazuh Agent Configuration
- Configuring Log Collection
- Sysmon Event Channel
- Forwarding Sysmon Logs to Wazuh
- Centralized Log Monitoring
- Importance of Log Integration in Cybersecurity

## 3. Learning Activities
- Studied the importance of integrating Sysmon with Wazuh.
- Learned how Sysmon generates detailed Windows system activity logs.
- Explored the role of Wazuh Agent in collecting Sysmon events.
- Understood how Windows Event Logs can be monitored through Wazuh.
- Learned about configuring the Wazuh Agent to collect Sysmon logs.
- Explored how collected logs are forwarded to the Wazuh Manager.
- Understood how centralized log monitoring helps security analysts investigate suspicious activities.

## 4. What I Learned
I learned that integrating Sysmon with Wazuh helps improve Windows security monitoring. Sysmon records detailed information about system activities, while the Wazuh Agent collects these logs and forwards them to the Wazuh Manager. I also understood how centralized log collection helps security analysts monitor endpoint activities, analyse events and identify potential security threats.

## 5. Tools Explored
- Wazuh Agent
- Wazuh Manager
- Wazuh Dashboard
- Sysmon (System Monitor)
- Windows Event Viewer
- Windows 11

## 6. Challenges Faced
Understanding the integration process between Sysmon and Wazuh, learning the log collection configuration and identifying how Sysmon events are forwarded to the Wazuh Manager.

## 7. Conclusion
The fourteenth day of training provided knowledge about Windows Event Logs and Sysmon integration with Wazuh. It helped me understand how different security logs can be collected and monitored through a centralized platform for effective security monitoring and threat detection.
