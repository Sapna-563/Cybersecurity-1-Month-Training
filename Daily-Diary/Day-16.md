# Day 16 – Security Log Analysis and Threat Detection

**Training Duration:** 1 Month  
**Day:** 16

## 1. Objective
To understand security log analysis and learn how security events are examined to identify suspicious activities, detect potential threats and support incident investigation.

## 2. Topics Covered
- Introduction to Security Log Analysis
- Importance of Log Analysis in Cybersecurity
- Understanding Security Events
- Windows Security Log Analysis
- Sysmon Event Analysis
- Introduction to Threat Detection
- Identification of Suspicious Activities
- Understanding Security Alerts
- Basic Incident Investigation
- Role of Log Analysis in SOC

## 3. Learning Activities
- Studied the importance of security log analysis in cybersecurity.
- Learned how security analysts examine system logs to identify unusual activities.
- Explored Windows Security Logs and Sysmon event information.
- Understood how suspicious login attempts can indicate potential security threats.
- Learned how to identify unusual process activities from security logs.
- Explored how security alerts help analysts identify possible incidents.
- Understood the role of log analysis in threat detection and incident investigation.

## 4. What I Learned
I learned that security log analysis is an important process used to identify suspicious activities and potential cyber threats. I understood how Windows Security Logs and Sysmon events provide useful information about system activities, login attempts and process execution. I also learned how security analysts examine these logs to detect unusual behaviour and investigate possible security incidents.

## 5. Tools Explored
- Wazuh
- Wazuh Dashboard
- Windows Event Viewer
- Sysmon (System Monitor)
- Windows Security Logs
- Windows 11

## 6. Challenges Faced
Understanding different security events, identifying suspicious activities from log records and distinguishing normal system behaviour from potentially harmful activities.

## 7. Conclusion
The sixteenth day of training provided knowledge about security log analysis and threat detection. It helped me understand how security events are examined to identify suspicious activities and how log analysis supports effective security monitoring and incident investigation.
