# Day 20 – Mimikatz Detection and Security Event Analysis

**Training Duration:** 1 Month  
**Day:** 20

## 1. Objective
To understand Mimikatz-related security threats and learn how security monitoring tools such as Wazuh can help identify suspicious activities through event logs and custom detection rules.

## 2. Topics Covered
- Introduction to Mimikatz
- Understanding Credential Theft
- Common Activities Associated with Mimikatz
- Security Risks of Credential Dumping
- Introduction to Threat Detection
- Wazuh Custom Detection Rules
- Monitoring Suspicious Process Activities
- Security Event Analysis
- Alert Generation and Investigation
- Importance of Endpoint Monitoring

## 3. Learning Activities
- Studied the purpose and functionality of Mimikatz.
- Learned about credential theft and its security risks.
- Understood how attackers may attempt to access sensitive authentication information.
- Explored how Wazuh helps monitor suspicious system activities.
- Studied how custom detection rules can identify Mimikatz-related events.
- Learned how security alerts help analysts investigate potential threats.
- Understood the importance of monitoring endpoint activities for detecting security incidents.

## 4. What I Learned
I learned that Mimikatz is a security tool that can be misused to extract sensitive authentication information from Windows systems. I understood the risks associated with credential theft and the importance of endpoint monitoring. I also learned how Wazuh custom detection rules can help identify suspicious activities and generate alerts for further security investigation.

## 5. Tools Explored
- Wazuh
- Wazuh Dashboard
- Wazuh Custom Rules
- Sysmon (System Monitor)
- Windows Event Viewer
- Windows Security Logs

## 6. Challenges Faced
Understanding credential theft techniques, identifying suspicious activities from system logs and learning how custom Wazuh rules help detect potential security threats.

## 7. Conclusion
The twentieth day of training provided knowledge about Mimikatz-related threats and security event analysis. It helped me understand the importance of detecting suspicious activities, monitoring endpoint events and using custom detection rules to improve cybersecurity monitoring.
