# Day 13 – Wazuh Agent Connection and Log Collection

**Training Duration:** 1 Month  
**Day:** 13

## 1. Objective
To understand how the Wazuh Agent connects with the Wazuh Manager and learn how security-related logs are collected from monitored systems for analysis and threat detection.

## 2. Topics Covered
- Wazuh Agent and Manager Communication
- Agent Connection Process
- Agent Registration and Authentication
- Wazuh Agent Status
- Introduction to Log Collection
- Windows Event Log Collection
- Security Event Monitoring
- Endpoint Monitoring
- Log Forwarding to Wazuh Manager
- Importance of Centralized Log Collection

## 3. Learning Activities
- Studied how Wazuh Agents communicate with the Wazuh Manager.
- Learned about the agent registration and authentication process.
- Explored how to check the connection status of Wazuh Agents.
- Understood how agents collect security-related information from monitored systems.
- Learned how Windows event logs can be collected for security monitoring.
- Explored how collected logs are forwarded to the Wazuh Manager.
- Understood the importance of centralized log collection in a SOC environment.

## 4. What I Learned
I learned that Wazuh Agents collect security-related information from endpoints and communicate with the Wazuh Manager. I understood how agent registration and authentication help establish a connection between the agent and manager. I also learned that centralized log collection helps security analysts monitor multiple systems, analyse events and identify suspicious activities.

## 5. Tools Explored
- Wazuh Agent
- Wazuh Manager
- Wazuh Dashboard
- Windows 11
- Windows Event Viewer
- Sysmon

## 6. Challenges Faced
Understanding the communication process between Wazuh Agent and Manager, checking agent connection status and learning how logs are collected and forwarded for analysis.

## 7. Conclusion
The thirteenth day of training provided knowledge about Wazuh Agent communication and log collection. It helped me understand how security information is collected from endpoints and sent to the Wazuh Manager for centralized monitoring, analysis and threat detection.
