## 3. Theoretical Knowledge
In a Security Operations Center (SOC), different security tools work together to detect, investigate, and manage security incidents.

Wazuh is used to monitor system activities and generate security alerts. Shuffle receives these alerts through webhooks and processes them using automated workflows.

VirusTotal helps analyze suspicious file hashes and provides threat intelligence information. TheHive is used to manage security incidents and maintain investigation details in the form of cases.

By integrating these tools, security teams can create an organized workflow for monitoring alerts, checking suspicious indicators, and managing incidents.
