# Day 04 – Virtualization and Lab Environment Setup

**Training Duration:** 1 Month  
**Day:** 04

## 1. Objective
To understand virtualization technology and learn how to create and manage virtual machines for setting up a cybersecurity practice lab environment.

## 2. Topics Covered
- Introduction to Virtualization
- Understanding Virtual Machines (VMs)
- Introduction to VirtualBox and VMware
- Overview of Windows and Linux Operating Systems
- Introduction to Kali Linux and Ubuntu
- Virtual Machine Configuration
- Hardware Requirements for a Cybersecurity Lab

## 3. Learning Activities
- Studied the concept and importance of virtualization.
- Learned how virtual machines work on a physical computer.
- Explored the features of VirtualBox and VMware.
- Understood the basic requirements for creating virtual machines.
- Learned about different operating systems used in cybersecurity labs.
- Explored how Windows and Linux environments are used for security monitoring and testing.

## 4. What I Learned
I learned that virtualization allows multiple operating systems to run on a single physical computer using virtual machines. I understood how VirtualBox and VMware help create isolated lab environments for cybersecurity practice. I also learned about the importance of CPU, RAM and storage when configuring virtual machines.

## 5. Tools Explored
- Oracle VirtualBox
- VMware Workstation
- Windows 11
- Kali Linux
- Ubuntu Linux

## 6. Challenges Faced
Understanding virtual machine configurations, allocating hardware resources and learning the differences between host and guest operating systems.

## 7. Conclusion
The fourth day of training provided knowledge about virtualization and cybersecurity lab environments. It helped me understand how virtual machines are used to create separate environments for learning, testing and practising cybersecurity activities.
