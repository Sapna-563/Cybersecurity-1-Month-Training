# Day 08 – Sysmon Installation and Configuration

**Training Duration:** 1 Month  
**Day:** 08

## 1. Objective
To understand the installation and configuration process of Sysmon on Windows and learn how to configure it for collecting detailed system activity logs for cybersecurity monitoring.

## 2. Topics Covered
- Introduction to Sysmon Installation
- System Requirements for Sysmon
- Downloading Sysmon from Microsoft Sysinternals
- Sysmon Installation Process
- Introduction to Sysmon Configuration Files
- Understanding Sysmon Event Types
- Configuring Process Monitoring
- Monitoring Network Connections
- Sysmon Log Generation
- Integration with Windows Event Viewer

## 3. Learning Activities
- Studied the steps involved in installing Sysmon on a Windows system.
- Explored Microsoft Sysinternals as the official source for Sysmon.
- Learned about Sysmon configuration files and their importance.
- Understood how configuration settings control the events recorded by Sysmon.
- Explored different Sysmon event types related to process creation and network connections.
- Learned how to view Sysmon logs through Windows Event Viewer.
- Understood how properly configured Sysmon helps collect useful security information.

## 4. What I Learned
I learned how Sysmon is installed and configured on a Windows system. I understood that Sysmon configuration files help control which system activities are monitored and recorded. I also learned that Sysmon generates detailed event logs, which can be viewed in Windows Event Viewer and used for security monitoring and threat investigation.

## 5. Tools Explored
- Sysmon (System Monitor)
- Microsoft Sysinternals
- Windows 11
- Windows Event Viewer
- Sysmon Configuration File

## 6. Challenges Faced
Understanding the Sysmon installation process, configuration settings and different event types. Learning how to identify useful Sysmon logs from the Event Viewer was also challenging.

## 7. Conclusion
The eighth day of training provided knowledge about Sysmon installation and configuration. It helped me understand how Sysmon collects detailed system activity logs and how these logs support security monitoring, threat detection and incident investigation.
