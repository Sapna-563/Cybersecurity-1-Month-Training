# Day 05 – Windows Operating System and Event Viewer

**Training Duration:** 1 Month  
**Day:** 05

## 1. Objective
To understand the Windows operating system and learn how to use Windows Event Viewer for viewing and monitoring system, application and security-related events.

## 2. Topics Covered
- Introduction to Windows Operating System
- Basic Windows Components
- Introduction to Windows Event Viewer
- Types of Windows Logs
- Application Logs
- Security Logs
- System Logs
- Importance of Event Logging in Cybersecurity
- Basic Security Event Monitoring

## 3. Learning Activities
- Studied the basic features and components of the Windows operating system.
- Explored Windows Event Viewer and its main features.
- Learned how to access Application, Security and System logs.
- Understood how Windows records different system activities and events.
- Explored how event logs help identify errors and suspicious activities.
- Learned the importance of Windows logs in security monitoring and incident investigation.

## 4. What I Learned
I learned that Windows Event Viewer is a built-in tool used to view and manage event logs generated by the operating system and applications. I understood the different types of logs, including Application, Security and System logs. I also learned that these logs help security analysts monitor system activities, identify errors and investigate suspicious events.

## 5. Tools Explored
- Windows 11
- Windows Event Viewer
- Task Manager
- Windows Services

## 6. Challenges Faced
Understanding the different categories of Windows event logs and identifying which logs are important for cybersecurity monitoring and investigation.

## 7. Conclusion
The fifth day of training provided knowledge about the Windows operating system and Event Viewer. It helped me understand how Windows records system activities and how event logs are useful for security monitoring, troubleshooting and incident investigation.
