# Day 11 – Wazuh Dashboard and Its Features

**Training Duration:** 1 Month  
**Day:** 11

## 1. Objective
To understand the Wazuh Dashboard and explore its features for monitoring security events, viewing alerts and analysing information collected from monitored systems.

## 2. Topics Covered
- Introduction to Wazuh Dashboard
- Overview of Dashboard Interface
- Wazuh Dashboard Features
- Security Events and Alerts
- Endpoint Monitoring
- Security Event Analysis
- Dashboard Navigation
- Understanding Security Monitoring Modules
- Importance of Dashboards in SOC Operations

## 3. Learning Activities
- Explored the Wazuh Dashboard interface and its main sections.
- Learned how to navigate different dashboard modules.
- Studied how security alerts and events are displayed.
- Understood how endpoint information is presented on the dashboard.
- Explored how security analysts monitor system activities using Wazuh.
- Learned how dashboards help organise and analyse security-related information.
- Understood the importance of Wazuh Dashboard in daily SOC monitoring activities.

## 4. What I Learned
I learned that the Wazuh Dashboard provides a graphical interface for managing and monitoring security information. I understood how security alerts, events and endpoint details are displayed in the dashboard. I also learned that security analysts use the dashboard to monitor systems, analyse alerts and identify potential security threats.

## 5. Tools Explored
- Wazuh Dashboard
- Wazuh Manager
- Wazuh Indexer
- Web Browser
- Windows 11
- Ubuntu Linux

## 6. Challenges Faced
Understanding the different sections of the Wazuh Dashboard and learning how to navigate its modules. Identifying important security information from the dashboard was also challenging.

## 7. Conclusion
The eleventh day of training provided knowledge about the Wazuh Dashboard and its features. It helped me understand how security events and alerts are displayed and how the dashboard supports security monitoring, log analysis and threat detection in a SOC environment.
