# Day 07 – Introduction to Sysmon (System Monitor)

**Training Duration:** 1 Month  
**Day:** 07

## 1. Objective
To understand Sysmon (System Monitor), its purpose and importance in monitoring Windows system activities and collecting detailed event logs for cybersecurity analysis.

## 2. Topics Covered
- Introduction to Sysmon
- What is System Monitor?
- Importance of Sysmon in Cybersecurity
- Features of Sysmon
- Monitoring Process Activities
- Monitoring Network Connections
- File Creation and Modification Events
- Windows Event Logging
- Role of Sysmon in Security Monitoring

## 3. Learning Activities
- Studied the concept and purpose of Sysmon.
- Learned how Sysmon helps monitor detailed activities on Windows systems.
- Explored the types of events recorded by Sysmon.
- Understood how process creation activities can be monitored.
- Learned how Sysmon records network connections and other system activities.
- Explored the importance of Sysmon logs in threat detection and security investigations.
- Understood how Sysmon logs can be used with security monitoring tools such as Wazuh.

## 4. What I Learned
I learned that Sysmon is a Windows system service and device driver that monitors and records detailed system activities in Windows Event Logs. It provides information about process creation, network connections and other system events. I also understood that Sysmon helps security analysts investigate suspicious activities and detect potential threats.

## 5. Tools Explored
- Sysmon (System Monitor)
- Windows 11
- Windows Event Viewer
- Windows Security Logs
- Wazuh (Overview)

## 6. Challenges Faced
Understanding the working of Sysmon, different types of events and how its logs help security analysts identify suspicious system activities.

## 7. Conclusion
The seventh day of training provided knowledge about Sysmon and its role in Windows security monitoring. It helped me understand how Sysmon collects detailed system activity information and how these logs are useful for threat detection and incident investigation.
