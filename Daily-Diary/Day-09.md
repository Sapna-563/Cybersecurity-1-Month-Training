# Day 09 – Introduction to Wazuh and Security Monitoring

**Training Duration:** 1 Month  
**Day:** 09

## 1. Objective
To understand Wazuh, its features and importance in cybersecurity. To learn how Wazuh helps monitor systems, collect security events and detect potential threats.

## 2. Topics Covered
- Introduction to Wazuh
- What is Wazuh?
- Importance of Wazuh in Cybersecurity
- Introduction to Security Monitoring
- Wazuh Architecture
- Wazuh Server and Agent
- Log Collection and Analysis
- Security Event Monitoring
- Introduction to Threat Detection
- Role of Wazuh in a SOC Environment

## 3. Learning Activities
- Studied the basic concept and purpose of Wazuh.
- Explored the main features of the Wazuh security monitoring platform.
- Learned how Wazuh collects and analyses security-related data.
- Understood the basic architecture of Wazuh.
- Explored the roles of Wazuh Server and Wazuh Agent.
- Learned how Wazuh helps monitor endpoints and identify suspicious activities.
- Understood the importance of Wazuh in Security Operations Center (SOC) activities.

## 4. What I Learned
I learned that Wazuh is an open-source security platform used for security monitoring, threat detection and log analysis. I understood that Wazuh uses agents to collect security-related information from monitored systems and sends it to the Wazuh Server for analysis. I also learned how Wazuh helps security analysts monitor endpoints, detect suspicious activities and investigate potential security incidents.

## 5. Tools Explored
- Wazuh
- Wazuh Server
- Wazuh Agent
- Windows 11
- Windows Event Viewer
- Sysmon

## 6. Challenges Faced
Understanding the Wazuh architecture, the difference between Wazuh Server and Agent, and how security logs are collected and analysed through the platform.

## 7. Conclusion
The ninth day of training provided knowledge about Wazuh and its role in security monitoring. It helped me understand how Wazuh collects and analyses security events and supports threat detection and incident investigation in a SOC environment.
