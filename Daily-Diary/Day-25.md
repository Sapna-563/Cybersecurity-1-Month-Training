- Connecting Security Tools with Shuffle

## 3. Theoretical Knowledge
Shuffle is a security automation platform that helps SOC analysts automate repetitive security tasks.

A workflow in Shuffle is a sequence of connected steps that perform specific actions automatically. Each workflow consists of different nodes that represent triggers, applications, and actions.

Webhooks allow external tools such as Wazuh to send security alerts to Shuffle. After receiving an alert, Shuffle can process the information and execute the configured workflow.
