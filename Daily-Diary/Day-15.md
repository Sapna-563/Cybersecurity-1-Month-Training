# Day 15 – Wazuh Log Collection and Monitoring

**Training Duration:** 1 Month  
**Day:** 15

## 1. Objective
To understand how Wazuh collects, stores and monitors security-related logs from different endpoints and learn how centralized log monitoring helps in identifying suspicious activities.

## 2. Topics Covered
- Introduction to Wazuh Log Collection
- Centralized Log Management
- Windows Event Log Collection
- Sysmon Log Collection
- Wazuh Agent Log Forwarding
- Security Event Monitoring
- Log Analysis
- Understanding Security Alerts
- Endpoint Activity Monitoring
- Importance of Log Monitoring in SOC

## 3. Learning Activities
- Studied how Wazuh collects security logs from monitored endpoints.
- Learned how Wazuh Agents forward collected logs to the Wazuh Manager.
- Explored the collection of Windows Event Logs and Sysmon events.
- Understood the importance of centralized log management.
- Learned how security-related events are displayed on the Wazuh Dashboard.
- Explored how log monitoring helps identify unusual system activities.
- Understood how security analysts use collected logs for investigation and threat detection.

## 4. What I Learned
I learned that Wazuh provides centralized log collection and monitoring for different endpoints. I understood how Wazuh Agents collect Windows Event Logs and Sysmon events and forward them to the Wazuh Manager. I also learned how security analysts use collected logs to monitor system activities, analyse security events and identify potential threats.

## 5. Tools Explored
- Wazuh
- Wazuh Agent
- Wazuh Manager
- Wazuh Dashboard
- Sysmon (System Monitor)
- Windows Event Viewer
- Windows 11

## 6. Challenges Faced
Understanding the log collection process, identifying different types of security events and learning how collected logs are monitored through the Wazuh Dashboard.

## 7. Conclusion
The fifteenth day of training provided knowledge about Wazuh log collection and monitoring. It helped me understand how security logs from different endpoints are collected and analysed through a centralized platform. This process plays an important role in security monitoring, threat detection and incident investigation.
