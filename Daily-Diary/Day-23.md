# Day 23 – TheHive Dashboard and Case Management

**Training Duration:** 1 Month  
**Day:** 23

## 1. Objective
To understand the TheHive dashboard and learn how security alerts are organized and managed as cases for incident investigation and tracking.

## 2. Topics Covered
- Introduction to TheHive Dashboard
- Understanding Security Alerts
- Introduction to Case Management
- Understanding Incident Information
- Organizing and Tracking Security Incidents
- Role of TheHive in SOC Operations

## 3. Theoretical Knowledge
TheHive is an open-source security incident and case-management platform used by security teams to organize and investigate security incidents.

The dashboard provides a structured way to manage incident-related information. It helps analysts review alerts, organize incident details and track investigations.

In a SOC environment, TheHive acts as a destination for alerts generated through security monitoring and automation tools.
